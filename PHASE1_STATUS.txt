KEY FEATURES
═════════════════════════════════════════════════════════════════════════════

✅ Automatic Build Pipeline
   Asset Conversion → Code Compilation → Linking → ROM Generation

✅ Incremental Builds
   SHA256 hashing of source files
   Only rebuild what changed
   Typical rebuild: 5-30 seconds

✅ Multi-SDK Support
   PVSnesLib, DotnetSnes, JavaSnes
   Configuration-driven
   Easy to extend

✅ Configuration System
   YAML/JSON project files
   Asset definitions
   Compilation targets
   Memory constraints

✅ Change Detection
   File hash tracking
   Persistent build state
   Smart rebuild skipping
